# Week 8 - Java Serialization

## Topic
Saving and Retrieving Bank Account Objects Using Serialization

## Objective
To learn how to save Java objects into a file using serialization and retrieve them using deserialization.

## Concepts Learned
- Serialization
- Deserialization
- Serializable interface
- ObjectOutputStream
- ObjectInputStream
- File Handling

## Implementation
The program stores bank account objects in a file using serialization and retrieves the saved objects when required.

## Learning Outcome
I learned how Java objects can be converted into a byte stream for storage and later reconstructed using deserialization.

## Technologies Used
- Java
- Object Serialization
- File Handling
