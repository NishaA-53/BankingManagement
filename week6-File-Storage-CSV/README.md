# Week 6 - CSV File Storage

## Topic
Saving and Retrieving Bank Account Details Using CSV Files

## Objective
To learn how to store and retrieve bank account details using CSV file handling in Java.

## Concepts Learned
- CSV File Handling
- Reading CSV files
- Writing CSV files
- FileReader
- FileWriter
- BufferedReader
- IOException

## Implementation
The program stores bank account details in a CSV file and retrieves the saved information when required.

## Learning Outcome
I learned how to store and retrieve banking information using CSV files in Java.

## Technologies Used
- Java
- CSV File Storage
- File Handling
