# Week 4 - TreeMap

## Objective

Implement a Banking Management System using Java TreeMap to store accounts in sorted order based on Account Number.

## Features

- Create Account
- Deposit Money
- Withdraw Money
- View Account Balance
- View All Accounts
- Duplicate Account ID Prevention
- Account Number Based Lookup
- Automatic Sorting of Account Numbers

## Data Structure Used

```java
TreeMap<Integer, BankAccount>
