# Week 7 - JSON File Storage

## Topic
Saving and Retrieving Bank Account Details Using JSON Files

## Objective
To learn how to store and retrieve bank account details using JSON file handling in Java.

## Concepts Learned
- JSON File Storage
- Reading JSON data
- Writing JSON data
- File Handling
- Data Serialization

## Implementation
The program stores bank account details in a JSON file and retrieves the saved information when required.

## Learning Outcome
I learned how JSON can be used to store structured banking information and retrieve it using Java.

## Technologies Used
- Java
- JSON
- File Handling
